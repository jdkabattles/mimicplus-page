This page checks a GOLD Verification Run receipt. Nothing you upload or paste leaves your browser. The check key is used only on this page to recompute the signature, and is never sent anywhere.

What this receipt proves, in plain words

It proves: what check ran, on what inputs, and when; what each of the six gates observed, pass or fail; and that this record has not been changed since it was signed.

It does NOT prove: that a product is good, safe, or worth buying. It is not a pass certificate. It is not a promise of future results. It is not investment advice. It is not a recommendation. It is only a record of one run.

Words we use

Hash = fingerprint. A hash is a fingerprint of a file or record. If the file changes, the fingerprint changes.

Signature = seal. The signature is a seal that only the key holder could make. It shows the receipt has not changed since it was sealed.

Merkle anchor = one fingerprint covering a day's receipts. We combine the day's receipt fingerprints into one fingerprint. If any receipt changes, the day's fingerprint changes.
