How to use Contract Gate.

It is not a Word file. The browser writes the file. You save the talk between your screen and the other computer, the same way as mimicplus. Chrome, F12, Network, right-click, save as HAR. Take the passwords out.

Last month, then this month

The first save is the copy you keep. That is last month's file. The next save is this month's file. Contract Gate compares them. If a box is missing or renamed, it stops and writes the name of the box. If you approve one box, the others still stop.

It does not watch the bank by itself. Someone saves the talk and runs the check. The check can run before a programmer ships, so the stop happens first.
