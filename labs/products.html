API Contract Prompts

40 copy-paste prompts for designing, specifying, testing and safely changing HTTP APIs.

Sections

  • API design review (7): resource model, naming, methods and status codes, payloads, idempotency, auth surface, and a consumer walkthrough.
  • OpenAPI spec generation and cleanup (7): drafting a spec from route handlers or examples, extracting components, linting, adding descriptions, tightening schemas, and checking for spec drift.
  • Contract testing (7): test plans, consumer-driven contracts, schema-validation tests, edge cases, mock fixtures, traffic checks, and a CI gate that needs no paid services.

  • Error and pagination conventions (6): error formats and catalogs, pagination strategy, filtering and sorting.
  • Docs and changelogs (6): endpoint reference, quickstart, changelog entries, release notes, docs accuracy review, and design guidelines.

In the zip

Each prompt has a purpose, the prompt text with {placeholders} for your own code, spec or examples, and a usage tip. They work with any capable AI chat assistant, but check every output against your real code and spec. The OpenAPI guide shows the approach.
