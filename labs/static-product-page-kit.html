03 — How it works

Deploy for $0

You need a free GitHub account. A custom domain is optional, and is the only possible cost.

  1. Replace the placeholders (product name, price, domain, checkout link and contact address) across the files. The README lists every one.
  2. Create a checkout link. A Stripe Payment Link or a Gumroad product URL. Both are free until you sell and take a fee per sale. The buy buttons are plain links, so the CSP never needs to allow checkout scripts.
  3. Swap the placeholder images for your own favicon and 1200×630 social image.
  4. Preview locally with python3 -m http.server 8000 and check every link.
  5. Upload the folder to the root of the main branch of a public GitHub repository, including .nojekyll. Keep your paid product file out of that repository.
  6. Turn on GitHub Pages: Settings > Pages > Deploy from a branch > main, / (root). Classic branch deploys on public repositories don't use paid Actions minutes.
  7. Optional: point a custom domain at it and tick Enforce HTTPS.

The guide on this site covers the same GitHub Pages steps. One limit to know: GitHub Pages can't set response headers, and a CSP meta tag can't set frame-ancestors, so clickjacking protection isn't available on plain GitHub Pages.
