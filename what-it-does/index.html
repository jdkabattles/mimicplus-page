What you feed it. What comes out.

You used a screen. The screen talked to another computer. The browser can save that talk. That saved talk is the only thing you feed mimicplus.

The input

The file is called a HAR. It is a list. Each line is a question the screen asked, and the answer the other computer sent. Take the passwords and tokens out first. Use a recording you are allowed to make. A second recording, from later, is how the alarm works.

The output

Four things. A written list of what that other computer actually sent. A copy of that list to hold against next time. A small program a coder can run to ask the same questions again. An alarm if next time a piece is missing or has a new name.

The alarm in the sample is a page gone, a price gone, a price back in cents, an order total gone, a grand total added. $199 once. The next recording is another $199.
