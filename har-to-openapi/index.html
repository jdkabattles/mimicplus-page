Convert a HAR to OpenAPI.

Written by Jonathan Battles. A HAR is the recording a browser already made. The partner did not send a specification that matches it. Copying the network tab by hand drops fields.

What the run writes

mimicplus takes one HAR you are allowed to record, secrets already removed. It writes OpenAPI, a versioned spec, a typed Python client, and tests. The sample run wrote spec.json, acme_client.py, and openapi.json from one session.

What it does not do

It does not call an API you are not allowed to call. It does not store secret values. It is $199 once. The next recording is another $199, not a subscription.

The check against a later recording is on the breaking-change page.
