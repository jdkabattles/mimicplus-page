How to use it.

You do not type the file. You do not send a Word document. The screen already talked to the other computer. The browser can save that talk.

1. Save the talk

In Chrome, open the screen you are allowed to use. Press F12. Open Network. Do the clicks you care about. Right-click the list. Save as HAR. Take the passwords out before you send it.

2. Pay once

$199. The key comes by email. It is one run, not a month.

Pay $199

3. Send the file with the key

Paste the key on forgingstack.com and attach the HAR. mimicplus reads the talk and writes the program that can call those same steps again, plus a list of the boxes that came back.

4. Save the talk again later

When the other side changes a box, save a new HAR. The check stops if a box is gone or renamed. That is the alarm. You do not have to read the file yourself.
